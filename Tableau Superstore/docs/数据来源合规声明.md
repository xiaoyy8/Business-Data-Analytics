## 二、获取方式的白名单说明

本项目数据获取方式：官方文件直接下载。

具体而言：

1. **使用官方发布的 Excel 文件**：从 Tableau 官网示例数据页面直接下载 `sample_-_superstore.xls`，
   保存到 `data/raw/` 目录，整个分析过程未对该原始文件做任何写操作（只读打开）。
2. **未使用 Python 数据接口库**：本项目未通过 API/数据库连接等方式获取数据，也未安装任何第三方数据集包。

## 三、合规性自述
- **未使用网络爬虫**：没有编写或运行任何爬虫脚本、没有请求任何非官方接口、
  没有绕过 robots.txt 或网站访问限制。
- **未使用盗版、破解或二次转售数据**：数据不来自论坛分享、网盘转存、淘宝/闲鱼售卖等非官方渠道。
- **未获取任何个人隐私数据**：Superstore 为 Tableau 官方**合成的演示数据**，
  其中的客户姓名（如 Darren Powers）、客户编号（如 DP-13000）、地址均为虚构标识符，
  不对应任何真实自然人；项目未尝试、也无法将其与真实身份关联（不做任何重识别尝试）。
- **未用于商业用途**：数据仅用于课程作业的分析与展示，不对外提供数据下载、不做商业分发。
- **未修改原始数据**：`data/raw/sample_-_superstore.xls` 保持下载时的原样，所有清洗结果另存于 `data/clean/`。

## 五、可追溯性

- 原始文件路径：`data/raw/sample_-_superstore.xls`
- 清洗脚本：`notebooks/01_数据获取与清洗.ipynb`
- 校验记录：`outputs/tables/t01_clean_report.csv`
- 数据规模与口径复核：`outputs/tables/t01_overview.json`

任何人拿到本仓库后，可用 `python run_all.py --only 01` 重新执行清洗，
并由上述两个文件核对本项目使用的数据规模与统计口径。
